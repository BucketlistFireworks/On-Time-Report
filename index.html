How This Works
  • Pick a start and end month, then click Run.
  • Every truck gets one row. Each month shows the miles driven that month (end minus start).
  • Start Odometer = first month's start reading. End Odometer = last month's end reading. Total = all months added up.
  • A dash means that month wasn't entered yet. Fix it on the Mileage tab.
  • Export Excel downloads the same table as a CSV that opens in Excel.
